# Mighty Snake OOP
A robust implementation of the classic Snake game developed using **Object-Oriented Programming** principles in **C++** with the **SFML** library.

## Key Features
* **Particle System:** Dynamic visual effects upon eating food or game over.
* **OOP Architecture:** Clear use of classes for Snake, Food, and Game states.
* **Smooth Rendering:** Integrated LERP (Linear Interpolation) for fluid movement.
* **Game Logic:** Progressive difficulty levels and real-time score tracking.
